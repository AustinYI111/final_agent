📚策略说明
📈
趋势跟踪策略 (TrendAgent)
基于双均线交叉信号（短期MA / 长期MA）。短期均线上穿长期均线时买入， 下穿时卖出。捕捉中长期价格动量趋势，适合趋势明显的行情。
信号 = sign(MA_short - MA_long)
↕️
均值回归策略 (MeanRevAgent)
基于布林带（Bollinger Bands）的反转策略。价格跌破下轨时买入， 回归均线时卖出。适合震荡行情，利用价格均值回复特性。
信号 = 1 if P < mu - k*sigma else (-1 if P > MA)
🧠
机器学习否决器 (MLAgent)
XGBoost 二分类模型，根据历史特征预测次日涨跌概率。 作为否决器参与融合：当预测上涨概率 ≥ 阈值时通过，低于阈值时否决买入信号。
否决条件 = ML_prob < prob_threshold
🔀
融合策略 (Fusion)
加权融合所有已选 Agent 的信号（默认等权重）。 通过 CoordinatorAgent 综合各 Agent 置信度，当综合信号强度超过阈值时触发交易。 MLAgent 作为否决器参与融合决策。
Score = Σ(w_i × conf_i); 买入 if Score > theta AND (ML不否决)
🔧
自定义策略 (CustomAgent)
插件式自定义策略。通过 UI 编辑 JavaScript 代码（遵循 A2A 协议）， 在后端由 PyMiniRacer (V8) 执行，输出 {signal, confidence}。 可与内置 Agent 一起参与投票融合。
return {signal: 'buy'/'sell'/'hold', confidence: 0.0~1.0}
